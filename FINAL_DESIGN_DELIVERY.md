## 📐 Design System Specifications

### Typography
```
Body Font:      Inter (clean, professional)
Heading Font:   Fraunces (premium, elegant)

Sizes:
- xs:  12px (small labels)
- sm:  13px (input text)
- base: 14px (body text)
- lg:  15px (larger text)
- xl:  16px (section text)
- 2xl: 18px (larger headings)
- 3xl: 24px (major headings)
- 4xl: 32px (page titles)
- 5xl: 40px (hero titles)
```

### Spacing System (4px base unit)
```
xs:  4px   (micro spacing)
sm:  8px   (tight spacing)
md:  12px  (standard)
lg:  16px  (comfortable)
xl:  24px  (generous)
2xl: 32px  (large)
3xl: 48px  (section)
4xl: 64px  (page)
```

### Border Radius
```
sm:  6px   (buttons, chips)
md:  8px   (inputs, cards)
lg:  12px  (cards, modals)
xl:  16px  (large modals)
2xl: 20px  (extra large)
```

### Shadow Hierarchy
```
xs: 0 1px 2px (subtle)
sm: 0 1px 3px (default)
md: 0 4px 6px (elevated)
lg: 0 10px 15px (high)
xl: 0 20px 25px (very high)
2xl: 0 25px 50px (maximum)
```

## 🎯 Key Design Features

### 1. **Modern Dark Theme**
- Professional, enterprise appearance
- Reduces eye strain for long work sessions
- Looks modern and premium
- Matches latest design trends

### 2. **Semantic Color System**
- Gold (#F59E0B) = Approvals, highlights
- Cyan (#10B981) = Success, completion
- Blue (#3B82F6) = Info, primary actions
- Red (#F87171) = Errors, rejections
- Colors communicate meaning intuitively

### 3. **Comprehensive Accessibility**
- High contrast ratios (19:1 on primary text)
- Clear focus indicators
- Keyboard navigation support
- Screen reader friendly
- WCAG 2.1 AA compliant

### 4. **Responsive Design**
- Mobile-first approach
- Adapts to all screen sizes
- Sidebar collapses on mobile
- Touch-friendly button sizes (44px minimum)
- Flexible grid layouts

### 5. **Smooth Interactions**
- Subtle animations (150-300ms)
- Hover effects on interactive elements
- Loading states with spinners
- Transition effects
- Professional feel
